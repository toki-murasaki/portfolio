プライバシーポリシー

Creator KPI Tracker（以下「本ツール」）における、利用者情報の取り扱いについて定めます。

2. 取得する Google ユーザーデータ（スコープ）

本ツールが Google アカウントに要求する権限は、利用者本人が認証画面で許可した以下の1つのスコープのみです。

  • YouTube Analytics のデータ（読み取り専用）
    https://www.googleapis.com/auth/yt-analytics.readonly
    利用者本人が管理する YouTube チャンネルの再生回数、視聴時間、登録者数、その他の統計指標を取得します。

本ツールは、上記スコープの範囲外にある Google ユーザーデータを一切取得しません。具体的には、氏名・メールアドレス等のプロフィール情報、連絡先、Google ドライブ上のファイルへアクセスすることはありません。また、動画やチャンネルの内容を投稿・編集・削除すること、利用者以外のチャンネルのデータを取得することもありません。

3. 認証方式の内訳

本ツールは 3 つの Google API を使用し、それぞれ異なる認証方式を用いています。Google スプレッドシートへの書き込みは、利用者の Google アカウントの権限（ユーザー OAuth）ではなく、これとは完全に独立したサービスアカウント認証で行います。

API認証方式権限・用途
YouTube Data API v3 API キー チャンネル・動画の公開情報の取得。ユーザー OAuth は使用せず、Google ユーザーデータも取得しません。
YouTube Analytics API v2 ユーザー OAuth 権限：https://www.googleapis.com/auth/yt-analytics.readonly
視聴時間などの Analytics データの読み取り。本ツールが利用者の Google アカウントへ要求する権限は、これ 1 つのみです。
Google Sheets API v4 サービスアカウント 取得した KPI を、運営者が管理する非公開の Google スプレッドシートへ記録します。利用者のユーザー OAuth による権限ではありません。運営者が用意したサービスアカウントに対し、対象スプレッドシートの編集権限をあらかじめ付与したうえで書き込みます。

4. データの利用目的

  • 利用者本人の YouTube チャンネルの KPI を、YouTube Analytics から読み取り専用で取得するため。
  • 取得した KPI を、ユーザー OAuth とは別のサービスアカウント認証を用いて、運営者が管理する非公開の Google スプレッドシートへ記録するため。
  • 取得と記録を継続的に行うための認証状態を維持するため。

上記以外の目的でデータを利用することはありません。

5. OAuth トークンの保存場所

Google の認証によって発行されるアクセストークンおよびリフレッシュトークンは、利用者本人の Windows PC 内にのみ保存されます。運営者のサーバーやその他の外部サービスへ送信・保管されることはありません。

6. KPI データの保存場所

取得した KPI は、運営者自身が管理する非公開の Google スプレッドシートへ保存されます。書き込みは、利用者の Google アカウントの権限ではなくサービスアカウント認証で行います。

  • 当該スプレッドシートは運営者本人が閲覧できます。
  • 一般公開はしません。閲覧できるのは運営者、および編集権限を付与された当該サービスアカウントに限られます。
  • 保存した KPI を第三者へ販売・共有することはありません。
  • 広告配信・広告のターゲティング、および AI・機械学習の学習用途に利用することはありません。

本ツールは運営者が自身のチャンネル運営のために使用する個人用ツールであり、運営者と利用者は同一人物です。

7. 第三者提供

本ツールが取り扱う Google ユーザーデータを、第三者へ販売、譲渡、貸与、または共有することは一切ありません。法令に基づく開示要請がある場合を除き、外部へ提供することはありません。

8. 広告・AI 学習への不使用

取得したデータを、広告配信・広告のターゲティング・その他のマーケティング目的で利用することはありません。また、機械学習モデルや AI の学習・訓練のために利用することもありません。

9. 保存期間と削除方法

  • OAuth トークン：本ツールを使用している間、利用者の Windows PC 内に保存されます。保存されたトークンファイルを削除するか、本ツールをアンインストールすることで削除できます。
  • KPI データ：運営者が管理する非公開の Google スプレッドシートに保存されます。運営者が必要に応じて、行またはスプレッドシート自体を削除することで消去できます。
  • アクセス権の取り消し：上記のデータ削除とは別に、Google アカウント側から本ツールへ付与した OAuth のアクセス権をいつでも取り消せます。手順は次章に記載しています。

10. アクセス権の取り消し

利用者は、Google アカウントの設定画面（https://myaccount.google.com/permissions）から、本ツールに付与したアクセス権をいつでも取り消すことができます。取り消し後、本ツールは Google ユーザーデータへアクセスできなくなります。

11. セキュリティ対策

  • Google API との通信は、すべて HTTPS による暗号化通信で行います。
  • 認証には Google の OAuth 2.0 を使用し、Google アカウントのパスワードを本ツールが取得・保存することはありません。
  • OAuth トークンは利用者の PC 内にのみ保存し、外部へ送信しません。
  • 利用者本人の Google アカウントに対しては、読み取り専用スコープ 1 つのみを要求します。Google Sheets や Google ドライブなどへの書き込み権限を要求することはありません。
  • Google スプレッドシートへの書き込みは、ユーザー OAuth とは別のサービスアカウント認証で行います。サービスアカウントの資格情報は運営者の PC 内で管理し、外部へ配布しません。

12. Google API Services User Data Policy への準拠

本ツールによる Google API から取得した情報の使用および他者への転送は、Google API Services User Data Policy（Limited Use requirements を含む）に準拠します。

Creator KPI Tracker's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

本ツールは Google LLC および YouTube の公式サービスではありません。個人が独自に開発したツールです。
